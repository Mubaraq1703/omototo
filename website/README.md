# Omototo Agro Allied Services Website

This is a professional website for Omototo Agro Allied Services, a cashew seed warehouse that connects farmers with buyers.

## Features

- Responsive design that works on all devices
- Modern React-based frontend with Vite for fast development
- Complete website with 6 main pages:
  - Home
  - About Us
  - Services
  - Process
  - FAQ
  - Contact

## Technology Stack

- React.js
- Vite
- CSS3
- React Router

## Setup Instructions

1. Clone the repository
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm run dev
   ```
4. Build for production:
   ```
   npm run build
   ```

## Customization

To customize the website for your specific needs:

1. Update the content in each page component in the `src/pages` directory
2. Modify the contact information in the `src/components/Footer.jsx` and `src/pages/Contact.jsx` files
3. Adjust colors and styling in `src/index.css` and `src/App.css`
4. Add your own images to the `src/assets` directory
